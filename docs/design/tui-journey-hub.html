Authority boundaries

Action path

Accum board → Judge (TradeSetup Action) → Plan inherits Action. Signal / Risk engines. Phase ledger is production memory for sequence — not a re-score on Judge view.

Browse path

Ticker desk & broker desk are cache dashboards. They never set ENTER/WATCH/AVOID. View ≠ Judge.

Paper path

Notebook only. Confirm write from plan. Not learning corpus. Not broker orders. Not Action authority.
